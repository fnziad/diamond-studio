# Diamond Studio

An experimental, offline ring visualizer with a procedurally generated adjustable hand. Explore stone shapes, settings, bands and lighting. No personal photographs, scans, certificates or private hand models are included.

Open index.html in a WebGL-capable desktop browser. Use Ring to set weight and dimensions, Bands for stacking, and Scene for light direction, intensity and motion. A text-based IGI PDF can be selected locally to extract its weight, shape, measured dimensions and selected grades. Review these values against the report. Image-only reports need manual entry. A report is not authenticated by importing it.

Carat is weight, and the weight-only size is an estimate. A report's measured dimension gives a better visual scale. Grades record report information and do not reconstruct inclusions or establish optical performance. The light and material controls provide an approximation; the hand, physical fit and diamond appearance are not measurement or gemological simulations.

For development, install dependencies with npm ci and run node build.cjs. Three.js, PDF.js and Mediabunny are bundled into the offline viewer.
