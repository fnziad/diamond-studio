# Diamond Studio

An experimental, offline ring visualizer with an adjustable anatomical hand. Explore stone shapes, settings, bands and lighting. No personal photographs, scans, certificates or private hand models are included. The hand mesh is adapted from the CC0 Innerscene anatomical hand, derived from the MakeHuman CC0 base. [Source and license](https://www.innerscene.com/tools/library/3d-parts/posable-anatomical-right-hand-f6098b4f).

Open index.html in a WebGL-capable desktop browser for the hand try-on, or diamond-inspector.html for a close view of a loose diamond or a diamond mounted in a ring. The two studios link to each other. The inspector offers face, side and pavilion views, four ring settings, three metals, lighting presets and PNG export. Use Ring to set weight and dimensions, Bands for stacking, and Scene for light direction, intensity and motion. A text-based IGI PDF can be selected locally to extract its weight, shape, measured dimensions and selected grades. Review these values against the report. Image-only reports need manual entry. A report is not authenticated by importing it.

Carat is weight, and the weight-only size is an estimate. A report's measured dimension gives a better visual scale. Grades record report information and do not reconstruct inclusions or establish optical performance. The inspector uses an illustrative interior-facet reflection layer to improve visibility rather than tracing the exact path of light through the stone. The light and material controls provide an approximation; the hand, physical fit and diamond appearance are not measurement or gemological simulations. The hand uses a generic skin material and has no modeled nails.

For development, install dependencies with npm ci and run node build.cjs. Three.js, PDF.js and Mediabunny are bundled into the offline viewer.
